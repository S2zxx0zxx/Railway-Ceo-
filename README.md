# The CEO: Company Simulator

An offline-first management game about rescuing a distressed single-product manufacturer. Premium static isometric office, landscape-first controls and interconnected business decisions. One React/TypeScript codebase for PWA and Android (Capacitor).

Development baseline: [master specification](docs/MASTER_BUILD_SPEC.md) · [execution ledger](docs/EXECUTION_LEDGER.md). This repository is in development; not a verified release.
